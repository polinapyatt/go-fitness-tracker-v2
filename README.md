# Модуль фитнес-трекера (ООП версия)

Учебный проект: рефакторинг модуля фитнес-трекера. 
Изначально приложение было написано с использованием процедурного подхода (набор разрозненных функций), а затем полностью переведено на объектно-ориентированную парадигму Go с использованием структур, методов, интерфейсов и встраивания (embedding).

> *Базовая версия проекта на функциях доступна по ссылке: [(https://github.com/polinapyatt/go-fitness-tracker)]*.
> *(Если ты удалила старый репозиторий, просто удали эту строчку)*

**Автор:** Полина Пятышина  
**Стек:** Go (стандартная библиотека: `time`, `strconv`, `strings`, `log`, `fmt`)

## Что изменилось по сравнению с базовой версией

- Логика распределена по изолированным пакетам (каждый пакет отвечает за свою зону ответственности).
- Данные пользователя вынесены в отдельную структуру `Personal` (пакет `personaldata`).
- Математические расчеты калорий, скорости и дистанции вынесены в пакет `spentenergy`.
- Для тренировок (`trainings`) и дневной активности (`daysteps`) созданы структуры с методами `Parse()` и `ActionInfo()`. В эти структуры встроена структура `Personal`.
- Реализован полиморфизм через интерфейс `DataParser` (пакет `actioninfo`), что позволяет обрабатывать разные типы активности (бег, ходьба, прогулки) с помощью одного и того же кода.

## Архитектура проекта

- **`personaldata`**: структура `Personal` (Имя, Вес, Рост) и метод `Print()` для вывода данных пользователя.
- **`spentenergy`**: экспортируемые функции для расчета дистанции (`Distance`), средней скорости (`MeanSpeed`) и потраченных калорий (`RunningSpentCalories`, `WalkingSpentCalories`).
- **`trainings`**: структура `Training` (встраивает `Personal`), методы `Parse()` для разбора строки с тренировкой и `ActionInfo()` для формирования отчета.
- **`daysteps`**: структура `DaySteps` (встраивает `Personal`), методы `Parse()` и `ActionInfo()` для учета дневной активности.
- **`actioninfo`**: интерфейс `DataParser` и функция `Info()`, которая принимает любую структуру, реализующую этот интерфейс, и выводит отчет.

## Структура проекта

```text
.
├── cmd/
│   └── tracker/
│       └── main.go       # Точка входа, демонстрация работы модуля
├── internal/
│   ├── actioninfo/       # Интерфейс DataParser и общая логика вывода
│   ├── daysteps/         # Логика дневной активности (прогулки)
│   ├── personaldata/     # Данные пользователя (имя, вес, рост)
│   ├── spentenergy/      # Математика (калории, скорость, дистанция)
│   └── trainings/        # Логика тренировок (бег, ходьба)
├── go.mod
├── go.sum
└── README.md
```

## Как запустить

Для запуска программы выполни в корне проекта:

```bash
go run ./cmd/tracker
```
